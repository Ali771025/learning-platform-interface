# Public edition

The repository preserves a compact source snapshot for portfolio review. No old Git history is imported. Private configuration, contracts/proposals, identity documents, operational databases, uploads, model weights, dependency bundles and generated results are excluded.

No new tests/builds were requested or executed. Existing source notices remain applicable. Do not interpret diagrams, documentation, example inputs or code that computes metrics as a claim of measured production performance.
